# Open file conceded to them — contest it

## Principles
1. **Oppose their rook on the file**, or double yours there; a file shared is a file not lost.
2. **Cover the entry squares** in your camp (the squares on your 1st/2nd ranks where their rook lands) with a minor piece or the king.
3. **Open a file of your own** elsewhere with a pawn break.
4. **Mirror (they gave you the file): take it, double, and aim for the seventh rank.**

## Deterministic check
- Conceded: a file with no pawns (or no student pawn) where an enemy rook/queen stands or can stand in 1, and no student rook/queen on it.
- Entry squares: squares on that file in the student's 1st–3rd ranks (from its side) that the enemy heavy piece can reach and that are attacked by no student piece.
- P1: a student rook reaches the file in 1 move with SEE ≥ 0 on the landing square.
- P2: a student minor or the king (endgame) reaches a square attacking every entry square, in ≤2.
- P3: a legal pawn break that opens another file where the student would have the first rook.
- P4: seats swapped; plus whether the 7th rank (2nd from their side) is reachable.

## Phrasings
1. They own that open file now; put a rook on it to challenge.
2. Guard the squares where their rook wants to land.
3. Can't take the file back? Open another one for yourself.
4. The open file is yours: double your rooks and head for the seventh.
5. A rook on an open file needs an entry square; take those away.
