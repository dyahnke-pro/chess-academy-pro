# A sacrifice must keep paying

## Principle
A sacrifice is an investment: after it, every move must force something; a quiet move gives them time and the sacrifice becomes a loss. A pawn given for a file is a practical bet, not a free pawn.

## When it applies / exceptions
Either seat.

## Deterministic check
- See recovery/compensation-lost.md. gambit-offer: the opponent's pawn sac opens a file/diagonal (file census before/after) and the engine rates taking it ≥ 0 but the follow-up within 30cp.

## Phrasings
1. After a sacrifice, every move has to threaten something.
2. A quiet move gave them time, and the attack faded.
3. The pawn is the price; the open file is what they bought.
4. A sacrifice is only sound if you've seen it to the end.
5. Taking the pawn is fine, but watch the file it opens.
