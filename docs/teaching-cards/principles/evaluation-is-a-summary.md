# The evaluation is a summary, not a promise

## Principle
An engine number summarises what each side can do; it doesn't say how to win.

## When it applies / exceptions
This is NOT a chess principle — it is a statement about engines; teach the plan instead.

## Deterministic check
- none (meta).

## Phrasings
1. The number is a summary; the plan is what wins.
2. A plus doesn't win by itself; find the plan behind it.
3. Being better is about what you can do next.
4. The evaluation says who's better, not how.
5. An edge only counts if you know how to use it.
