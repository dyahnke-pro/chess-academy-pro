# RPG demo sprite credits

The character sprites in this folder are from the **Universal LPC Spritesheet**
project (Liberated Pixel Cup), used here for the `/rpg-demo` proof-of-concept.

- Source: https://github.com/jrconway3/Universal-LPC-spritesheet
- Generator: https://liberatedpixelcup.github.io/Universal-LPC-Spritesheet-Character-Generator/
- Licenses: **CC-BY-SA 3.0** and **GPL 3.0** (dual-licensed)

LPC art requires **attribution** and is **share-alike** — if we ship an RPG
piece set built from these assets, we must credit the LPC artists and keep the
art under a compatible license. Full author lists for each asset live in the
source repo's `CREDITS` files.

Files:
- `body-dark.png`, `body-light.png`, `body-female-light.png` — base bodies,
  832×1344 (13×21 grid of 64px frames): spellcast / thrust / walk / slash /
  shoot / hurt animations × 4 directions.
